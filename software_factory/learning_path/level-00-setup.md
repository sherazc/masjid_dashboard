# Level 0: Setup (15 min)

## Goal
A safe throwaway project, and a way to see what agents are doing.

## Concepts
- **Throwaway project:** a small folder you can delete. Mistakes cost nothing.
- **Observability:** being able to see what each agent did. You can't manage what you can't see.

## Steps
1. Create `software_factory/playground/`.
2. Make it a git repo (`git init`). Git is your undo button.
3. Add a tiny `project_context.md` (one paragraph: a small todo-list CLI in a language you know).
4. Open Claude Code in that folder.
5. Learn how to view a running agent's activity in your terminal/IDE.

## Document it
Screenshot: the folder, and Claude Code open in it.

## Check yourself
- Can you delete `playground/` without caring?
