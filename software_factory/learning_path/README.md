# Multi-Agent Learning Path

Goal: understand how agents work together (orchestrator, sub agents, teams). Learning only, not development.

## Rules
- Each level: 30 minutes or less.
- Do one step at a time. Ask me for the next step.
- At each "Document it" box, take a screenshot or write a Google Doc note.
- All practice happens in a throwaway project: `software_factory/playground/`. `MasjidDashboardWeb` is not touched until Level 9.

## Levels
| Level | Topic | You will learn |
|---|---|---|
| [0](level-00-setup.md) | Setup | Throwaway project, how to watch agents |
| [1](level-01-vocabulary.md) | Vocabulary | Agent, tool, context, orchestrator, sub agent, team |
| [2](level-02-first-sub-agent.md) | First sub agent | Delegate one task, see what comes back |
| [3](level-03-custom-sub-agent.md) | Custom sub agent | Give an agent a role and limited tools |
| [4](level-04-orchestrator.md) | Orchestrator | One agent directing several in parallel |
| [5](level-05-contracts-and-roles.md) | Contracts and roles | Planner, implementer, reviewer pipeline |
| [6](level-06-parallel-worktrees.md) | Parallel work | Git worktrees so agents don't collide |
| [7](level-07-agent-teams.md) | Agent teams | Agents that message each other |
| [8](level-08-guardrails.md) | Guardrails | Tests, hooks, review gates, cost |
| [9](level-09-your-role.md) | Your role | Architect/manager role, plan for MasjidDashboardWeb |
