# Level 7: Agent Teams (30 min)

## Goal
See agents talk to each other, not only to the orchestrator.

## Concepts
- **Sub agent vs team member:** a sub agent only reports up. A team member can message peers.
- **Shared task list:** team members pick up and mark tasks.
- **Cost:** more agents talking means more tokens.

## Steps
1. Read the Claude Code docs on agent teams (10 min max). This may be an experimental feature, so check how to enable it.
2. In `playground/`, start a team of two: one writes code, one writes tests.
3. Watch them message each other.
4. Compare with Level 5, where the orchestrator relayed everything.

## Document it
Screenshot: a message from one agent to another. Write when a team beats sub agents, and when it doesn't.

## Check yourself
- Which costs more, and why?
